## The picture in one paragraph

## What would change this read

The constructive read, that this is a pullback inside a repair, fails if the
fifty-day count falls back under about 700, its washout-day reading. It fails if
the two-hundred-day count falls under about 1,030, the washout-day level. It fails
if a second washout arrives, 300 or more stocks falling four and a half percent in
one session. It also fails if the VIX rises above its thirty-week average, about
13.5, while big fallers stay above about 50 a day. That would show fear building
on steady selling.

The cautious read, that the repair has turned over, fails if big risers return
above about 150 within the next few sessions while big fallers drop back under
about 20. It fails if the two-hundred-day count climbs back above about 1,150. It
fails if the large-cap list above the day's average price returns above about 60.
It also fails if a thrust day arrives, 300 or more stocks jumping four and a half
percent in one session. That would give the washout low the proof it still lacks.
