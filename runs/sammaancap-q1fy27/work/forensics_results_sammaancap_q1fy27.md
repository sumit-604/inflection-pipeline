Para 13 (line 1411) discloses a breach of financial covenants on "borrowing arrangements OTHER THAN the above Debentures." Note 4 (line 1695) attests compliance only for "the debt securities to which this certificate pertains." Different debt populations; both statements are true. Do NOT read Note 4 as suppressing the breach; do NOT read the breach as covering the Debentures. Reported under F5-a as a genuine RED-FLAG/FORWARD-SIGNAL. No payment default: the outstanding-default format (lines 1051, 1054) shows nil default — breach ≠ default, consistent.

2. OCR_UNCERTAIN cover ratios — the 400dpi ADDENDUM (lines 1767-1770) resolves the garbled 200dpi figures: Cover on Book Value 1.21 (not 41.21), Cover on Market Value 1.62 (not 4.62), Pari-Passu Security Cover Ratio 1.18 (OCR "4.18"). These are plausible NBFC cover multiples. Note: a ~1.18x pari-passu cover is a thin cushion — worth source-PDF confirmation and a forward watch, but consistent with compliance for debentures whose trust-deed minimum is typically ~1.0-1.1x.

3. OCR column "conflict" 14,031.41 vs 44,031.17 (line 1623-1624) — NOT a same-cell conflict: the addendum (line 1759) shows 14,031.1x is the exclusive-charge column and 44,031.17 the total column for "Debt securities to which this certificate pertains." Two different columns, not a discrepancy. Still requires source-PDF confirmation (matrix is OCR-fragile).

4. ANNEXURE_REFERENCED_NOT_FOUND — "Annexure I" (minimum asset-cover requirement, line 1316) is genuinely absent from the filing. Reported under F14-b. Any precise minimum-cover comparison is unconfirmable from this extract.

5. Consol Note 11 gain Rs.1,154.93cr vs SA Note 12 gain Rs.996.25cr (lines 537 vs 813) — expected standalone-vs-group scope difference (subsidiary co-lending/assignment volume), not a drafting error; noted, not flagged as inconsistency.
