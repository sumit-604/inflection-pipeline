# Data sources

Written 2026-10-04 (second pass). One row per cached series. Status PRIMARY = the named source served it; VERIFIED MIRROR = a public GitHub copy served it and its month_end and month_avg sums were checked equal to the primary series on 2026-10-04; MIRROR = public copy, not checked against the primary; FAILED = no data, the model runs without it. Re-running `python fetch.py --primary` on a machine that reaches these hosts regenerates this table from scratch.

How the second pass was fetched. The cloud shell and the laptop's sandboxed shell both refuse FRED, Yahoo, World Bank, EIA and NSDL. The series below marked PRIMARY were pulled on 2026-10-04 through two routes with the laptop's real network: FRED monthly aggregates (fredgraph.csv, fq=Monthly) and the Yahoo chart JSON through a web fetcher, and daily Yahoo and FRED data plus the NSDL year tables through the Claude desktop browser running code on the source page. Month-end, month-average and last-observation-date were computed in that code with the same rule as fetch.py (last valid daily close per month; a final month whose last observation is before the 15th is dropped). Every file was checked back against a checksum (row count and sum of month_end) computed at the source before it was saved.
