### 1.9.1 DILUTED SHARE COUNT AT 31-MAR-2026: what the note does and does not give

OBSERVATION, stated as the AR presents it, no inference added:

- The EPS note prints ONE row for the share denominator: "Weighted Average number
  of equity shares (b)". There is NO separate row for a diluted weighted average
  number of shares. There is no row for "weighted average number of equity shares
  that would be issued on conversion of all the dilutive potential equity shares",
  even though the narrative paragraph directly above defines diluted EPS by that
  addition.
- Both the basic line and the diluted line carry the SAME formula label "[(a)/(b)]"
  and the SAME divisor (b). Basic EPS equals diluted EPS in both years because the
  AR divides by the same denominator twice.
- There is NO statement anywhere in the note that the options were anti dilutive.
  Search of the AR for the word "anti" or "antidilutive" returns nothing in the EPS
  notes.
- 1,94,125 options were outstanding at 31-Mar-2026 at an exercise price of Rs 3.80
  against a grant-date share price of Rs 238 to Rs 258 (section 1.8.2). The note
  gives no diluted denominator that reflects them.

THEREFORE, answering the prompt's direct question:
DILUTED SHARE COUNT AT 31-MAR-2026 (a weighted average number of shares used for
diluted EPS, distinct from the basic count) = NOT DISCLOSED. The note where it
would normally be found is consolidated Note 35 Earning Per Share, page 132, and
standalone Note 34 Earning Per Share, page 173. Both notes carry only one share
count row.

What IS disclosed and can be quoted:
- Weighted average number of equity shares used for BOTH basic and diluted EPS,
  FY2026: 22,03,62,377.05 (standalone Note 34, page 173) / 2,203.62 lakh
  (consolidated Note 35, page 132).
- Weighted average for FY2025: 21,19,43,369.86 / 2,119.43 lakh.
- CLOSING share count at 31-Mar-2026: 22,03,94,625 (Note 15, page 123; Directors
  Report, page 54).
- Options outstanding at 31-Mar-2026 that are not in any of those counts: 1,94,125,
  of which 46,000 exercisable (Annexure VI, page 71; Note 44, page 142).
