## PART 4: FINDINGS

**CRITICAL — QUESS "Rs176cr Labour Code pass-through" is not in the transcripts.**
Location: 06-peers.md Part 2B ("QUESS took a one-time Rs176cr revenue/cost pass-through (May-2026 and Feb-2026 calls)") and Part 3 coverage map, QUESS Q4 FY26 (May-2026) row ("Rs176cr one-time Labour Code revenue/cost pass-through").
Checked QUESS-Concall_Feb_2026_Transcript.txt and QUESS-Concall_May_2026_Transcript.txt in full for "176," "Labour Code," "pass-through," and "gratuity." The only genuine Labour Code cost figure in either call is Rs7cr (Feb-2026, confirmed accurate elsewhere in the same report). The only occurrence of "176" in the May-2026 call is "INR 13,176 crores," the Staffing Solutions segment's full-year FY26 revenue — an unrelated top-line figure, not a Labour Code cost. A genuine "INR176 crores" figure does exist in the corpus, but it belongs to **UDS** (adjusted EBITDA for the Avon-affected BSS division, Jun-2026 call, wholly unrelated to Labour Code). This looks like either a misread of "13,176" or a cross-company conflation with the UDS figure. This number is load-bearing for B06's Part 2B argument that peer Labour Code impacts dwarf CMS's own guided drag — that comparison should be recomputed with the real, much smaller Rs7cr QUESS figure once this is corrected, materially weakening the "far larger absolute events" claim.

**MAJOR — AGSTRA "receivable days" quote cited to the wrong transcript, wrong analyst.**
Location: 06-peers.md Part 1, claim 7, and the introductory structural paragraph, both citing "(AGSTRA-Concall_Jul_2024, p.mid, Amit / Saurabh Lal exchange on 'high receivable days.')"
The exchange quoted ("we are running at high receivable days... pivoting from transaction-based and ATMs to non-transaction-based ATMs...") is real and verbatim, but it is in **AGSTRA-Concall_Feb_2024** (Q3 FY24), analyst Amit from HDFC — not in the Jul-2024 (Q1 FY25) call as cited. Grep of the full Jul-2024 transcript for "receivable" returns zero matches; the only working-capital exchange in that call is a different analyst (Ankit Kanodia) asking about high "day's payables," a different metric. This is used to support "the single most consequential finding in this stage" (the DSO/receivables contradiction), so the wrong anchor matters even though the DSO verdict itself still stands on the RADIANTCMS/SIS anchors (Part 3). B06's own Part 3 coverage-map row for AGSTRA Q3 FY24 (Feb-2024) correctly places "chronic receivable-days concern raised by analyst pre-CIRP" there — so the correct location was identified elsewhere in the same report, just not carried through consistently into the Part 1 citation.

**MINOR — AGSTRA ATM-decline quote misattributed to "Ravi Goyal."**
Location: 06-peers.md Part 1, claim 5 ("(AGSTRA-Concall_Nov_2024, p.~9/mid, Ravi Goyal-line response to Naitik Mutha.)")
Quote content is verbatim correct ("a lot of consolidation has been done across in the industry by public sector banks... 26,000 ATMs"), but the actual speaker is **Stanley Johnson**, not Ravi Goyal. Content and page location are right; speaker attribution is wrong.

**MINOR — SIS page-anchor convention inconsistent with the bracket-marker standard used elsewhere.**

**MINOR — AURIONPRO Nov-2025 "no relevant terms matched" is not accurate.**
Location: 06-peers.md Part 3 coverage map, AURIONPRO Q2 FY26 (Nov-2025) row.
