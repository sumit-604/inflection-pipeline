# Market notes

Things found while reading the briefs or brainstorming. Newest at the top.
One entry per finding. Each entry names the trade date it came from, so the
brief and the raw files for that day can be opened again.

This file goes to GitHub every night with the data, and the claude.ai project
reads it, so every brainstorm starts with these notes already in view.

To add a note: type it under a new dated heading below, or tell Claude Code
"note: ..." and it will add it here with the date.
