# KERNEX — FY28 Top-line / Bottom-line Model (scenario build)

Built 2026-08-14, off Q1 FY27 actuals + thesis base case. Purpose: test
whether the Q1 FY27 blockbuster growth is sustainable into FY28.

STATUS OF NUMBERS
- ANCHORED (disclosed): Q1 FY27 revenue Rs503.58 Cr; Q1 clean PAT Rs101.26 Cr;
  Q1 EBITDA margin 32.33%; order book Rs3,641 Cr incl GST (filing L272);
  FY26 baseline rev ~Rs430 Cr, clean PAT ~Rs72 Cr, net debt Rs135 Cr.
- MODEL (our thesis file): FY27 base rev Rs1,200 Cr, clean PAT Rs239 Cr,
  CFO Rs50 Cr, FCF -Rs30 Cr, net debt Rs350 Cr.
- ASSUMPTION (built here, flagged): everything FY28. No company guidance exists.

## KEY INSIGHT — this is an order-book conversion, not a demand engine
Revenue = execution of a FIXED backlog (percentage-of-completion). The backlog
is the fuel tank. Growth sustains ONLY if new orders refill the tank as fast as
execution drains it. So FY28 is driven by ONE variable: new order inflow.

Convert book to revenue-equivalent: Rs3,641 Cr incl GST / 1.18 (18% GST
ASSUMPTION) = ~Rs3,086 Cr ex-GST executable backlog, as of ~Q1 FY27 end
(i.e. AFTER Q1's Rs504 Cr was already burned).

Book-to-forward-revenue coverage = 3,086 / ~1,600 (FY27E) = ~1.9x, and the
book FELL below the Rs4,500 Cr red line this quarter. A durable multi-year
grower usually carries 2.5-3x+ AND rising. Kernex is <2x AND shrinking. That
is the sustainability tell, before any modelling.

whole thesis: the P&L is not the problem, cash conversion is.

## SUSTAINABILITY VERDICT
1. The blockbuster growth is a "pig in the python" — a fixed backlog being
   recognised, not a self-refilling demand engine.
2. It sustains into FY28 ONLY in Base/Bull, which REQUIRE Rs1,500-3,500 Cr of
   fresh Kavach wins per year — a step-change vs history.
3. The only hard, disclosed inflow signal we have (order book) already flashed
   the warning this quarter: below the red line and down toward the ~Rs6,500 Cr
   the thesis wanted. Observed evidence = Bear-to-Base, not Bull.
4. Every scenario that KEEPS the top line growing makes the balance sheet WORSE
   (net debt up, FCF negative). Growth is not de-risking; it is leveraging.
5. Therefore: on current evidence the growth is NOT reliably sustainable, and
   the accounting bottom line will look healthy even if it isn't. AVOID stands.

## WHAT WOULD CHANGE THE VERDICT (watch, in order)
- New large Kavach order inflow (national rollout tenders) taking book back
  above Rs4,500 Cr and toward Rs6,500 Cr -> moves Base/Bull live.
- FY26 AR: CFO turning positive and debtor days falling below 200.
- Q1 concall: management naming a specific WC-funding plan (QIP timing/size).
