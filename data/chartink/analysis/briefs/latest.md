**4. The money improved and still falls short.** Turnover was about 530 crore, the most on an up day since 16 October. The heavy selling days each carried about 610. A wide day on turnover above that level would be the one thing this bounce still lacks.

## What would change this read

The read is a broad repair on the short and middle clocks, led by the small companies, on money that improved but has not matched the sellers. It turns worse if a heavy selling day returns and the next session fails to answer it. A day of 300 or more hard fallers would be the first sign. A short count back under about 870, Tuesday's level, would say Wednesday was a single burst. A long count back under about 580, the 23 October low, would erase the bounce. New yearly lows back above about 300 would say the same. A VIX close above about 18 would say fear has taken charge.

The cautious read fails if the money arrives and the long clock follows. The first test is a wide up day on turnover above about 610 crore. Wednesday reached about 530. The second test is the long count above about 940, the 16 October repair high. Wednesday reached 872. The third test is new yearly highs past about 50 while new lows stay under 100. Wednesday had 45 highs and 41 lows, so that test is close. The fourth test is a second wide day within a week, with 300 or more hard risers again. A VIX close under 15 would support the turn. Two of these in the same week, with the short count holding above 1,000, would change the read from repair to a new uptrend.
