### 2C. Growth embedded in capex

The prescribed arithmetic (capex under execution × historical fixed-asset
turnover = implied incremental revenue) is NOT APPLICABLE here: the 6,000
MTPA line is a completed, historical project (commissioned 1 Apr 2025), not
capex currently under execution, and the rating agency explicitly states no
major capex is planned for FY27-FY28 (RATING.txt p.5). There is no forward
capex pipeline to run the formula against.

Shown instead, with its missing inputs flagged, is the alternative
"utilisation-headroom" arithmetic on the already-completed base: theoretical
volume headroom = (100% − 31%) / 31% = 2.23x the FY25 utilised-capacity-linked
volume, if the existing 24,300 MTPA base were run to full utilisation. This
is NOT converted into a revenue percentage because per-tonne/per-bag
realisation is NOT FOUND (B04 input_gaps) and the volume-vs-revenue split by
standalone/consolidated entity is not disclosed. `capex_embedded_growth_pct`
is therefore carried as 0 in the YAML block (not computable on the specified
method), with this note preserved.
