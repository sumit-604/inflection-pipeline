# Method note: the 2026-09-09 run (third run)

Operator: Keerti Kaushik. Eight names screened in one session.

## What was reachable

Nothing was downloadable. The network policy allowed GitHub only. The proxy
answered 403 to the CONNECT for `docs.bull-ai.in`, `screener.in`, `bseindia.com`
and every rating-agency host. WebFetch returned EGRESS_BLOCKED. No collector
script could run and no PDF is held on disk.

Bull AI MCP answered, but only in part. Two endpoints timed out on every call,
at every page range and every payload size, across the whole session:

- `get_document_chunks` (both the `pdf_content` and the `annual_reports`
  collections)
- `search_company_documents`

Those are the two document readers. The 2026-09-08 run used the first of them
to stand in for the corpus. This run could not.

These endpoints did answer, and every one of them is document-grounded and
returns a document code plus a page number:

- `list_document_availability` (the corpus ledger)
- `get_company_guidance` (management quotes and delivery claims)
- `get_company_counterparties` (customers, suppliers, group companies)
- `get_company_market_transactions` (bulk, block and insider dealing)
- `get_company_corporate_actions`
- `get_company_classification`, `search_companies`

## What that means for a citation

A cite on a 2026-09-09 card, written `doc LP2iax p.14`, points at
`https://docs.bull-ai.in/d/LP2iax#page=14`. The page number is the source PDF's
own, so the operator can open it from a machine with egress.

The important limit: these are Bull AI's extractions of the filed document, not
text this session read. Nobody here read a page. A quote on a card is a quote
Bull AI reports, at a page Bull AI names. Treat every one as PENDING SOURCE
VERIFICATION until the PDF is opened.
