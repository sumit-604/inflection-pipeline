### FINDINGS — Gate 0

**FINDING G-1 (MAJOR) — history_downgrade field set true while the report's own
text states no history downgrade applies.**
Location: B01 YAML `history_downgrade: true` vs CLASSIFICATION section
("Data confidence: 10 years → 10+ yrs, full confidence. No history-length
downgrade applies.").
The only "history downgrade" mechanism the framework defines is the
data-confidence tier downgrade (3–4 yrs LIMITED → downgrade classification one
tier). At 10-year full confidence that mechanism does NOT fire, and the body
correctly says so. The YAML boolean is therefore internally contradicted by the
report and, read at face value by a downstream consumer, misstates a structured
handoff field. The transition/recovery signal it is trying to carry is already
and properly carried by FLAG-GATE0 and the history_downgrade *reason* string, so
the boolean is at best redundant and at worst misleading. Does NOT change the
AVOID classification. Recommended value: `false` (with the recovery narrative
left in FLAG-GATE0 where it belongs).

**FINDING G-2 (MINOR) — ROCE computed via a substituted denominator against a
"do not substitute" formula.**
Location: B01 methodology notes / Block A.
Framework fixes ROCE = EBIT ÷ (Total Assets − Current Liabilities) under a
header that reads "FORMULA DEFINITIONS (fixed, do not substitute alternatives)."
B01 uses EBIT ÷ (Net Worth + Borrowings) because the CSV carries no
current/non-current split. This is a genuine deviation from the fixed formula.
It is mitigated to MINOR because: it is disclosed explicitly, applied
consistently across all 10 years and all peers, the proxy (Net Worth +
Borrowings) is an accepted Capital-Employed identity, and the strict-compliance
alternative (mark A1/A2/A4 all N/A) would be less informative and equally
defensible. Decision-neutral. No number re-scored on my side (Verifier A owns
value accuracy); flagged as a formula-selection deviation only.

**Gate 0 verdict: rules applied as written. Recomputed classification = AVOID
(concur). No CRITICAL. 1 MAJOR (handoff-field semantics), 1 MINOR (formula
substitution).**
